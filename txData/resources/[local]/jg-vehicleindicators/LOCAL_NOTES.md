# jg-vehicleindicators

Source: [jgscripts/jg-vehicleindicators](https://github.com/jgscripts/jg-vehicleindicators)

This standalone resource adds synced vehicle turn signals and hazard lights.

## Status

Installed and enabled in `txData/server.cfg`.

## Binds

- Left indicator: `Left Arrow`
- Right indicator: `Right Arrow`
- Hazard lights: `Up Arrow`

Players can change the binds in-game:

`Escape -> Settings -> Key Bindings -> FiveM -> jg-vehicleindicators`

## Requirements

- OneSync Infinity / OneSync enabled

`txData/server.cfg` now includes:

```cfg
set onesync on
ensure jg-vehicleindicators
```
